# e-plantShopping

## Paradise Nursery - Plant Shopping Application

A React-based e-commerce web application for purchasing plants online, built as part of the IBM Developing Front-End Apps with React course.

### Project Name: e-plantShopping

### Features
- Landing page with "Welcome to Paradise Nursery" heading and a "Get Started" button
- Product listing page with multiple plant categories (Air Purifying, Aromatic Fragrant, Insect Repellent, Medicinal, Low Maintenance)
- Add to Cart functionality using Redux Toolkit (RTK)
- Shopping cart with quantity controls (increment, decrement), item removal, and total cost calculation
- Continue Shopping and Checkout buttons

### Tech Stack
- React (with Vite)
- Redux Toolkit (RTK) for state management
- CSS for styling

### Getting Started

```bash
npm install
npm run dev
```
